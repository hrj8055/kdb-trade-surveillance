# kdb+ AI Trade Surveillance Platform

Real-time trade surveillance in kdb+/q: detects spoofing, layering, wash trading,
front-running and marking the close, links trades with trader chats, and uses AI
to reduce false positives and explain alerts.

**Status:** under active development. Step 1 (tickerplant + schemas) complete.

Stack: KDB-X, kdb+tick, PyKX, Python, Ollama, Streamlit.
